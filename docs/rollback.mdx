title: Rollback
description: Git-based checkpoints and careful rollback.
---

Trace creates a **checkpoint** before every monitored run and lets you restore it
later. Rollback is always git-based, and it never destroys work without asking.

## Checkpoints

Before a run, in a git repository, Trace:

- records the current commit hash
- records whether the working tree is dirty
- creates a lightweight checkpoint with `git stash create` when the tree is
  dirty, which captures the dirty state **without** disturbing your working tree,
  or uses `HEAD` when the tree is clean
- captures the git diff before and after the run

Checkpoints are labelled by run, for example `trace/run-<run_id>-before`. List
them with:

```bash
trc checkpoints
```

## Rolling back

```bash
trc rollback
```

This restores the most recent checkpoint, or asks you to choose when several are
available. You can also roll back from the **Rollback Center** in the dashboard.
Skip the confirmation prompt with `-y`/`--yes` when you are certain:

```bash
trc rollback -y
```

<Warning>
Rollback never wipes your work without confirmation. A stash-based checkpoint is
re-applied; a clean-tree checkpoint resets to the recorded commit. Review the
target before confirming.
</Warning>

## What rollback does and does not touch

Rollback restores the git state captured at the checkpoint. It does not undo
side effects that live outside git: it will not un-send a network request,
un-drop a database, or restore a file that was never tracked. This is exactly why
the [command guard](/command-guarding) blocks or requires approval for
irreversible operations (dropping a database, overwriting a raw device) rather
than relying on rollback to save you. Rollback protects the working tree; the
guard protects everything git cannot.

After a successful rollback, the run's status becomes `rolled_back`. See
[Agent Runs](/agent-runs).

## Requirements

Rollback and checkpoints require git. If your project is not a git repository,
`trc init` warns you, and runs are recorded without checkpoint or rollback
support. Trace will not run `git init` for you. To get rollback, run `git init`
yourself and commit a baseline before relying on it.
