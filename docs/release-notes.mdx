## v1.3 - One-command agent onboarding

- **`trc integrations install`** wires up your coding agents in one step.
  `trc integrations install all` installs the Claude Code hooks, the Codex
  wrapper, and the Cursor, Windsurf, and OpenCode MCP servers, patching each
  agent's own config file idempotently and backing it up first. Install one at a
  time with `trc integrations install <agent>`.
- **`trc integrations status`** detects which agents are connected right now by
  reading their config files, and reports the daemon and GitHub token state.
- **Windsurf and OpenCode** join Cursor as MCP integrations, all backed by the
  same local daemon. Windsurf uses `~/.codeium/windsurf/mcp_config.json`;
  OpenCode uses `~/.config/opencode/opencode.json`.
- **`trc replay <run_id>`** replays a run's timeline at its original recorded
  pace (or `--fast` to print immediately), reading the same data as `show`,
  `patch`, and `risks`.
- **npm-only install** on every platform: `npm install -g trace-dev` installs the
  `trc` command.

## v1.2 - Fully deterministic: no API key, add Ratify

- **Removed every LLM feature.** The judge panel, model prompting mode, the
  prompting coach, and PR-history mining are gone. Trace runs entirely on its
  deterministic engines (command guard, secret scanner, policy engine) and
  **requires no AI/LLM API key** anywhere.
- **Ratify** runs the deterministic policy engine over a GitHub pull request's
  files and returns a `pass` / `review` / `block` verdict, from the dashboard's
  **Ratify** tab, the `trc ratify <pr>` command, or `GET /api/github/ratify`. All
  three share one implementation.
- **`trc check <file>`** scans any file or script (or stdin) through the guard and
  secret scanner without executing it, with a non-zero exit on
  require_approval/block for CI gating.
- **Red-team benchmark**: an adversarial corpus (dangerous commands including
  evasions, planted secrets, unsafe prompts) run through the real engines and
  scored for recall and false positives, surfaced in `trc self-check`,
  `GET /api/benchmarks/redteam`, and the dashboard's **Benchmarks** page.
- Hardened the command guard against evasions (pipe-to-sudo-shell,
  download-then-exec, base64-to-shell, `find ... -delete`, raw block-device
  writes) and expanded the secret detector's provider set.
- `trc review-diff` and the GitHub CI Action became policy-engine only.
- Rule-pack override env var renamed `TRACEGUARD_RULES_PATH` to
  `TRACE_RULES_PATH` (the legacy name is still honored).

## v1.1 - Rebrand to Trace

- Renamed the project from **TraceGuard** to **Trace**. The binary is now `trc`.
- Removed prompt compression and the agent-launching surface. Trace is scoped to
  recording, guarding, and reviewing agent runs.
- Global directory moved to `~/.trace` (database `trace.db`); per-project
  directory moved to `<project>/.trace`.
- **GitHub**: read directly from the repo (including private repos) via `trc
  github` and the dashboard GitHub page.
- Docs moved to GitHub Pages; landing page with a per-OS install block.

## v0.1.0 - Local-first MVP

Initial release.

**Core**
- The CLI: `init`, `run`, `dashboard`, `rollback`, and `daemon start|stop|status`.
- Local Axum daemon bound to `127.0.0.1`, with port discovery from `8757`.
- Local SQLite persistence and the local React dashboard (Dashboard, Run
  Timeline, Patch Review, Cost Center, Risk Center, Rollback Center).

**Monitoring**
- Run recording with checkpoints, file watching, and command output capture.
- Git checkpoints and git-based rollback.
- Rule-based command guarding (allow / warn / require approval / block).
- Local secret detection with redaction.
- Cost tracking with honest partial-data handling.
- Deterministic patch diagnosis.

**Surfaces**
- Public landing site and Mintlify documentation.
- Integration scaffolds for GitHub, Claude Code, Codex, and Cursor.

> Dates and versions are updated as releases are tagged.
