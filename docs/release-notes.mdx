## v1.2 — Fully deterministic: no API key, add Ratify

- **Removed every LLM feature.** The 3-LLM judge panel, Model Prompting Mode,
  the prompting coach, and PR-history "doctrine" mining are gone. Trace now runs
  entirely on its deterministic engines (command guard, secret scanner, policy
  engine) and **requires no AI/LLM API key** anywhere.
- **Ratify** — run the deterministic policy engine over a GitHub pull request's
  files and get a `pass` / `review` / `block` verdict, from the dashboard's new
  **Ratify** tab, the new `trace ratify <pr>` command, or
  `GET /api/github/ratify`. All three share one implementation.
- **`trace check <file>`** — scan any file or script (or stdin) through the
  guard + secret scanner without executing it; non-zero exit on
  require_approval/block for CI gating.
- **Red-team benchmark** — an adversarial corpus (dangerous commands incl.
  evasions, planted secrets, unsafe prompts) run through the real engines and
  scored for recall / false positives, surfaced in `trace self-check`,
  `GET /api/benchmarks/redteam`, and the dashboard's **Benchmarks** page.
- Hardened the command guard against evasions (pipe-to-sudo-shell,
  download-then-exec, base64-to-shell, `find … -delete`, raw block-device
  writes) and expanded the secret-detector provider set.
- `trace review-diff` and the GitHub CI Action are now policy-engine only
  (the `--judge` flag and `enable-judge` input were removed).
- Rule-pack override env var renamed `TRACEGUARD_RULES_PATH` → `TRACE_RULES_PATH`
  (the legacy name is still honored).
- Dashboard nav updated: the Judge Panel and Prompting Coach pages are gone;
  a **Ratify** page is added. Token Spend (cost tracking) is unchanged.

## v1.1 — Rebrand to Trace, TraceCompress removed

- Renamed the project from **TraceGuard** to **Trace**. The binary is now
  `trace` (previously `trg`, with `traceguard` as a long alias — both are
  gone).
- Removed **TraceCompress** (prompt compression, output-budget presets, and
  the `compress-prompt` / `run --compress` commands) and the agent-launching
  surface (`agents`, `use`, `launch`, `guard`, `rules`). Trace is scoped to
  recording, guarding, and reviewing agent runs.
- Global directory moved to `~/.trace` (database `trace.db`); per-project
  directory moved to `<project>/.trace`.
- GitHub repo, Docs Pages, Homebrew tap, and npm package all moved to the
  `trace` name.
- **GitHub**: read directly from the repo (including private) via `trace
  github` and the dashboard GitHub page.
- **Docs** moved to GitHub Pages; **landing** with OS-aware install.
- Homebrew tap, install scripts, npm wrapper, `trace update`.

## Earlier — pre-rebrand groundwork (as TraceGuard)

- **TraceCompress**: prompt compression + output discipline (since removed —
  see above).
  - Modes: Normal, Concise, Bare Mode (strict response rules).
  - Preserved-constraints checklist, removed-redundancy summary, conflict
    detection, response-rules block, output-budget presets (Tiny/Short/Normal/Detailed).
  - CLI: `trg compress-prompt --mode <m> [--output-budget <p>]` and
    `trg run --compress`.
  - Dashboard: **Prompt Compressor** page.
  - Privacy: `[prompt_compression]` config; `prompt_history = false` stores only
    estimates + metadata, never raw prompt text. External-LLM compression was
    opt-in.
  - New endpoints under `/api/prompt-compressor/*`.
- `trg update` self-update command.
- MIT `LICENSE` added.

## v0.1.0 — Local-first MVP (as TraceGuard)

Initial release.

**Core**
- `trg` CLI: `init`, `run`, `dashboard`, `rollback`, `compress-prompt`,
  `daemon start|stop|status`.
- Local Axum daemon bound to `127.0.0.1`, port discovery from `8757`.
- Local SQLite persistence and the local React dashboard (Dashboard, Run
  Timeline, Patch Review, Cost Center, Risk Center, Rollback Center, Utilities).

**Monitoring**
- Run recording with checkpoints, file watching, command output capture.
- Git checkpoints and Git-based rollback.
- Rule-based command guarding (allow / warn / require approval / block).
- Local secret detection with redaction.
- Cost tracking schema with honest partial-data handling.
- Deterministic patch diagnosis.

**Productivity**
- Prompt Compressor (local, deterministic) and output-budget controls.

**Surfaces**
- Public landing site (`apps/landing`, Vercel).
- Mintlify documentation.
- Integration scaffolds: GitHub, Claude Code, Codex, VS Code, Cursor.
- Installers: Homebrew tap, shell script, PowerShell script, optional npm
  wrapper.

> Dates and versions are updated as releases are tagged.
