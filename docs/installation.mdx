---
title: Installation
description: Install the trc CLI on macOS, Linux, or Windows with npm.
---

Trace ships a single binary, `trc`. Install it with npm on macOS, Linux, and
Windows:

```bash
npm install -g trace-dev
```

That is the only supported install path on every platform. The npm package is
named `trace-dev` because the bare `trc` and `trace` names are already taken on
npm. The command it installs is `trc`.

## Requirements

- **Node.js 18 or newer.** npm ships with Node, and the package uses Node both to
  install and (for the MCP integrations) to run.
- **Git**, for checkpoints, rollback, and project detection. Trace never runs
  `git init` for you.

The package downloads the matching prebuilt binary from GitHub Releases during
install. If that step is ever skipped (for example with `npm install
--ignore-scripts`), the first `trc` run fetches the binary automatically, so the
CLI is self-healing.

## Pin a version

To install a specific release, set `TRACE_VERSION` for the install:

```bash
TRACE_VERSION=v1.3.0 npm install -g trace-dev
```

## Verify the install

```bash
trc --version   # prints "Trace 1.3"
trc --help
```

Then run the built-in system check, which inspects your toolchain, the daemon,
key paths, and which AI CLIs it can find:

```bash
trc doctor
```

A healthy machine reports git, node, and npm versions, a passing policy-engine
self-check, and your database path. Anything missing is printed with a short,
actionable fix. See [Troubleshooting](/troubleshooting) if `trc doctor` flags
something.

## Update

If you installed with npm, update the same way:

```bash
npm install -g trace-dev@latest
```

The `trc update` command also updates the binary in place to the latest GitHub
release.

## Build from source

You need Rust and Node.js. The dashboard is a separate app that gets embedded
into the daemon in release builds.

```bash
git clone https://github.com/TaxCollector23/trace
cd trace

# Build the dashboard (embedded into the daemon in release builds)
cd apps/web && npm install && npm run build && cd ../..

# Build the CLI (the binary is named trc)
cargo build --release -p trace-cli
./target/release/trc --help
```

The workspace is a Cargo workspace with three crates (`trace-cli`,
`trace-daemon`, `trace-core`) plus the web app. See
[Concepts and Architecture](/concepts) for how they fit together.
