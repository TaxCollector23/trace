---
title: Installation
description: Install the trace CLI on macOS, Linux, or Windows.
---

Trace ships a single binary, `trc`. Install it with npm on macOS, Linux, and
Windows:

```bash
npm install -g trace-dev
```

Requires Node.js 18+. The npm package is named `trace-dev` (the bare
`trc`/`trace` names are already taken on npm); the command it installs is
`trc`. The package downloads the matching prebuilt binary from GitHub Releases —
if that step is ever skipped (for example `--ignore-scripts`), the first `trc`
run fetches it automatically.

Pin a version with `TRACE_VERSION=v1.3.0 npm install -g trace-dev`.

## Verify

```bash
trc --version
trc --help
```

## Build from source

You need Rust and Node.js.

```bash
git clone https://github.com/TaxCollector23/trace
cd trace

# Build the dashboard (embedded into the daemon in release builds)
cd apps/web && npm install && npm run build && cd ../..

# Build the CLI (the binary is named `trc`)
cargo build --release -p trace-cli
./target/release/trc --help
```
