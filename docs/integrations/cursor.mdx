---
title: Cursor
description: Connect Cursor so Trace can show sessions, review edits, and stop risky shell commands.
---

Trace uses Cursor's hooks for live session and command visibility. It also adds
Trace's local MCP tools so you can ask Cursor about recent runs, changes, and
undo points.

## Connect it

```bash
npm install -g trace-agent-cli
trc integrations install cursor
```

Or connect all supported agents:

```bash
trc integrations install all
```

The installer writes a shared Trace hook, the MCP server, and Cursor's
`~/.cursor/hooks.json`. It preserves your other hooks and creates a backup before
changing an existing file. Cursor normally reloads the hook settings; reopen
Cursor if the status stays disconnected.

## What Trace does

- At session start, Trace opens a run automatically.
- Before Cursor runs a shell command, Trace checks it. A **block** decision is
  denied before the command starts.
- After a shell command or file edit, Trace records what happened in the
  timeline and reviews the working tree.
- At session end, Trace captures the final changes and closes the run.

File review is after the edit, so it reports a problem and gives you an undo
point rather than pretending it can stop an edit that already landed.

The shell guard fails closed: if Trace cannot reach its local daemon, the hook
returns a denial instead of silently letting an unchecked command run.

## Check the connection

```bash
trc integrations status
trc dashboard
```

Open the dashboard while Cursor is working. The current run should show Cursor,
the project folder, commands, changes, blocked actions, and the timeline.
