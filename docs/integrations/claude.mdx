---
title: Claude Code
description: Connect Claude Code so Trace can show the session and stop risky commands.
---

Trace connects to Claude Code through Claude's own hooks. It starts a Trace run
when a Claude session starts, records commands and file changes, and checks each
Bash command before Claude runs it.

## Connect it

Install Trace once, then connect every supported agent:

```bash
npm install -g trace-agent-cli
trc integrations install all
```

Or connect only Claude Code:

```bash
trc integrations install claude
```

The installer starts Trace, prints the local dashboard link, and backs up any
settings file it changes. Restart Claude Code after installation. Claude Code
also has a `/hooks` screen you can use to confirm that Trace is listed.

## What Trace does

- Before a Bash command runs, Trace checks it. A command classified as **block**
  is denied before Claude can execute it.
- After a file edit or command, Trace adds the action to the run timeline and
  reviews the working tree.
- When the session ends, Trace captures the final changes and closes the run.

File review happens after the file edit has landed. It can warn Claude and show
the finding in the dashboard, but it cannot undo an edit that already happened.
Use the dashboard's undo point or `trc rollback` if you decide to remove it.

## Check the connection

```bash
trc integrations status
trc dashboard
```

Start a new Claude session and look for it under **Current run**. The dashboard
should show the agent, working folder, commands, changes, and any blocked action.

## If hooks are unavailable

The wrapper still works with older Claude Code versions or unusual launchers:

```bash
trc run "claude fix the login bug"
```

The wrapper gives Trace a complete run around the command. The hook install is
the better option for live command decisions inside an already-running Claude
session.
