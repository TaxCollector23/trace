---
title: opencode
description: Connect Trace to opencode, the open-source terminal coding agent, over MCP.
---

[opencode](https://github.com/sst/opencode) is an open-source terminal coding
agent that speaks the Model Context Protocol (MCP). Trace connects to it as a
local MCP server — the same daemon-backed server used by the Cursor and
Windsurf integrations — so opencode can classify commands, record runs, and
read patch and rollback state through Trace. Everything stays on `127.0.0.1`.

## Install

```bash
trc integrations install opencode
# or wire up every agent at once:
trc integrations install all
```

This writes the MCP server to `~/.trace/integrations/opencode/index.js` and
idempotently patches your global opencode config at
`~/.config/opencode/opencode.json` (XDG-aware), backing it up first and
preserving any config you already have. The entry it adds:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "trace": {
      "type": "local",
      "command": ["node", "/Users/you/.trace/integrations/opencode/index.js"],
      "enabled": true
    }
  }
}
```

opencode merges every config file under `~/.config/opencode/`, so this
coexists with other MCP servers you already run. Restart opencode to load it.

## Verify

```bash
trc integrations status
```

opencode should read **connected**. Start the daemon with `trc daemon start`
if it isn't already running.

## Tools exposed

`trace_check_command`, `trace_get_recent_runs`, `trace_start_run`,
`trace_end_run`, `trace_record_event`, `trace_get_patch_summary`,
`trace_get_rollback_options`.

If the daemon isn't running, tool calls fail closed and opencode proceeds
without Trace — the integration never blocks your agent.
